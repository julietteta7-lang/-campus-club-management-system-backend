## Project Description

This project is a Spring Boot REST API for managing campus clubs, students, club categories, meeting rooms, membership applications, and membership fees.

## Technologies Used

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
- Postman

## Steps to Run the API

### Prerequisites

- Java 17 or later
- Maven
- PostgreSQL
- Git

### 1. Clone the repository

```bash
git clone https://github.com/julietteta7-lang/campus-club-management-system-backend.git
```

### 2. Open the project

Open the cloned project folder in Visual Studio Code or another Java IDE.

### 3. Configure the database

Create a PostgreSQL database named:

```text
campus_club_management_system_db
```

Update the database URL, username, and password in `src/main/resources/application.properties` to match your PostgreSQL configuration.

### 4. Run the application

Open a terminal in the project directory and run:

```bash
mvn spring-boot:run
```

### 5. Access the API

The API runs locally at:

```text
http://localhost:8080
```

Use Postman to test the available REST API endpoints.
